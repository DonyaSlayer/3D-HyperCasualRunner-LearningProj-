Zombie Destroyer 3D (Mobile Runner)

A hyper-casual endless runner for Android with procedural generation and progression systems.

Key Features
Procedural Generation: Endless map generation with increasing difficulty.
Gameplay Mechanics: Buffs (clones, ammo types) & Debuffs systems.
Data Persistence:** Saving player stats (Coins, Wave progress) using `PlayerPrefs`.
AI: Two types of zombie behaviors.

Technical Implementation
UI: Adaptive mobile UI.
Platform: Android (Touch input integration).
